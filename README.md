# BOSS 职位复制助手

在 BOSS 直聘职位详情页一键复制完整招聘信息，直接粘贴到 ChatGPT、Claude、Gemini 或其他 AI 工具中进行岗位分析。

## 功能

- 复制职位概览和职位描述
- 适配 BOSS 直聘动态加载的职位详情页
- 复制成功后提供明确的状态反馈
- 不需要登录、不收集数据、不访问远程服务器

## 安装

1. 下载或克隆本项目。
2. 在 Chrome 或 Edge 地址栏打开 `chrome://extensions/`（Edge 可使用 `edge://extensions/`）。
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目目录。
5. 打开任意 BOSS 直聘职位详情页，点击右下角的“复制职位信息”。

## 使用方式

复制后，将内容粘贴到 AI 工具中即可继续进行岗位匹配、薪资判断、面试准备或简历优化。

## 隐私说明

扩展只读取当前 BOSS 直聘职位详情页中已经显示的职位信息，并将结果写入系统剪贴板。项目没有后台服务、统计代码、远程请求或账号信息采集。
